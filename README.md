NEON / PC E-commerce MVP с 3D-конфигуратором сборок
Стек: FastAPI SQLAlchemy Jinja2 Vanilla JS Three.js (GLB) SQLite
Роль: Full-stack разработчик (от проектирования БД до 3D-интерфейса)

Полноценный MVP интернет-магазина для сборки ПК. Проект охватывает весь цикл: от витрины с товарами и интерактивного 3D-конфигуратора до административной панели с управлением заказами и интеграцией с Telegram для мгновенных уведомлений.

Ключевые особенности (Highlights)
Интерактивный 3D-конфигуратор: Клиент собирает ПК в реальном времени. Система на лету проверяет совместимость (сокеты CPU/материнской платы, типы ОЗУ) на клиенте и сервере. Реализовано на Three.js с использованием GLB-моделей и привязкой к слотам (CPU, DIMM, PCIe).

Надежная серверная логика: Цена рассчитывается только на сервере с использованием Decimal (защита от подмены цены на клиенте). При оформлении заявки остатки товаров атомарно уменьшаются (с откатом транзакции при ошибке).

Безопасность: Реализована CSRF-защита, безопасное хеширование паролей администратора, строгая валидация форм (включая обязательное согласие на обработку персональных данных).

Интеграция с Telegram: Менеджер получает уведомления о новых заявках прямо в мессенджер. Если токен не задан - заявки просто падают в админку, ничего не ломается.

Гибкая админка: Позволяет управлять каталогом (CRUD), отслеживать статусы заказов (Новый → В работе → Выполнен) и защищает компоненты, уже включенные в готовые сборки, от случайного удаления.

Покрытие тестами: Интеграционные тесты на Python (unittest) проверяют маршруты, безопасность и бизнес-логику. JS-тесты (Node.js) проверяют совместимость сокетов и корректность 3D-моделей.

Быстрый запуск (Windows PowerShell)
Клонируйте репозиторий и перейдите в папку:

bash
git clone https://github.com/KipSverlo/Pc_project.git
cd Pc_project
Создайте виртуальное окружение и установите зависимости:

bash
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Настройте окружение (скрипт создаст .env со случайным ключом):

bash
.\.venv\Scripts\python.exe setup_env.py
Заполните базу тестовыми данными (демо-сборка и компоненты):

bash
.\.venv\Scripts\python.exe seed.py
Запустите сервер:

bash
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload
Доступные страницы:

Витрина: http://127.0.0.1:8000/

Конфигуратор: http://127.0.0.1:8000/configurator

Админка: http://127.0.0.1:8000/admin (демо-доступ admin/admin по умолчанию)

Структура проекта
backend/ - FastAPI-приложение, модели SQLAlchemy, безопасность, интеграция с Telegram.

frontend/ - ассеты 3D-моделей (GLB).

static/ - CSS и JS (включая логику 3D-сцены, парсинг сокетов).

templates/ - Jinja2-шаблоны страниц.

tests/ - интеграционные тесты.

seed.py - скрипт идемпотентного заполнения БД.

browser-check.mjs - сценарий E2E-проверки в браузере.

Технические детали
3D-конфигуратор:

static/sockets.js - профиль креплений для материнской платы (ASUS B550-F): слоты CPU, DIMM A1/A2/B1/B2, PCIe, M.2.

static/assembly.js - нормализация осей GLB-моделей, процедурная генерация корпуса и БП.

static/pc-scene.js - управление сценой, подсветкой, выбором планок памяти.

Защита и логика:

В MVP не включен платежный шлюз (только заявки).

Неоплаченные заявки резервируют товар. Автоматического снятия резерва нет (менеджер корректирует остаток вручную).

Ограничение частоты запросов к публичным формам хранится в памяти одного процесса (достаточно для MVP).

Перед продакшеном (Production Notes)
Этот код — локальный MVP. Перед реальным запуском необходимо:

Заполнить реквизиты продавца в .env (SELLER_*) и условия доставки/оплаты (SITE_*).

Заменить демо-пароль администратора и сгенерировать надежный SECRET_KEY.

Включить HTTPS и флаг COOKIE_SECURE=true.

Настроить резервное копирование БД и мониторинг.

Внедрить антиспам для публичных заявок (например, rate limiting).

Модели в 3D-конфигураторе иллюстрируют категории товаров и не являются точными копиями. Логическая проверка охватывает только сокет и тип памяти. Реальные габариты, мощность и совместимость BIOS требуют проверки менеджером.
