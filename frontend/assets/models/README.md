# Модели комплектующих

Сюда помещаются cpu.glb, motherboard.glb, ram.glb, gpu.glb и storage.glb.
API автоматически публикует model_url для существующих файлов. При отсутствии файла используется условная геометрия из static/studio.js. При ошибке загрузки GLB интерфейс сообщает о резервном представлении.

Предоставленные пользователем ссылки на luolangaga/tubatools скачать не удалось: raw.githubusercontent.com вернул 404 для cpu.glb, github.com прервал соединения для всех пяти файлов. Лицензия исходных моделей не проверена; сторонние модели не включены. Three.js 0.170.0 распространяется по MIT, текст лицензии находится в static/vendor/THREE-LICENSE.txt.

## Обновление 2026-11-02

Все пять GLB успешно скачаны через gh-proxy.com с ветки master. Предыдущее описание отсутствующих файлов больше не актуально. Авторы, источники, лицензия CC BY 4.0 и изменения перечислены в /static/model-credits.html. GLTFLoader использует локальный MeshoptDecoder. Геометрические заглушки удалены.
